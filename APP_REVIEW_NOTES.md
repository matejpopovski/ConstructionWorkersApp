# App Review Notes Draft

Construction Gossip is a social app for construction workers to share workplace experiences, pay context, safety notes, and employer reviews.

Reviewer test path:

1. Create an account or use the demo reviewer account provided in App Store Connect.
2. Complete onboarding by choosing a state, city, job/position, and optional profile photo.
3. Create a work report from the Post tab.
4. View the report on Home and Profile.
5. Comment on a report and reply to a comment.
6. Use Search to find workers, job reports, companies, jobs, and locations.
7. Open a profile, follow/message the user, and test image messages.
8. Share a post externally or send it to another user in chat.
9. Report a post/comment using the menu.
10. Block a user from their profile.
11. Delete the account from Privacy settings.

Moderation and safety:

- Users can report posts and comments.
- Users can block profiles.
- Anonymous posts show as Anonymous Worker to other users.
- Private street address information is not shown publicly.
- Image uploads are optimized before storage.

Current build note:

- The app uses local persistence for the current build. Production launch should connect the same service layer to the production backend before public scale.
