## Get Help

Use the [Construction Gossip support request form](https://github.com/matejpopovski/ConstructionWorkersApp/issues/new?title=Support%20request&labels=support) to report an app problem.

Please include:

- Your username, but never your password
- A short description of the issue
- Screenshots when helpful
- Your iPhone model and iOS version

Do not post private messages, passwords, authentication links, or other sensitive personal information in a public support request.

## Safety

For harassment, impersonation, private information, illegal content, or unsafe behavior, use the in-app report menu whenever possible. Block a profile to hide that person's content and prevent further interaction.

## Account Access

Password recovery is available from the login screen.

## Account Deletion

Permanent account deletion is available inside the app from Profile > Settings. If account access prevents deletion, submit a support request without including your password.
